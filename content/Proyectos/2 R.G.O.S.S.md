---
Su principal funcion es ser capaz de encender el servidor principal usando la red local en la que se encuentra, pudiendo acceder de forma remota desde cualquier parte del mundo con la ayuda de [[7 Tailscale]]. 

Aqui están los pasos para configurar el [[6 LAN Wake-up]]


# Servidor de finanzas
---
Otra funcion de R.G.O.S.S es almacenar los datos relacionados a mis finanzas, para esto hace uso de una base de datos ligera como es **SQLite** y aloja una aplicacion web usando **Flask** con la que podemos hacer el registro de los gastos y ver el analisis estadistico.

El esqueleto de la aplicacion web es el siguiente:

``` Plaintext
RGOSS_app/
├── venv/                 # Entorno virtual (librerías de Python)
├── app.py                # El motor principal (Flask)
├── expss.db              # La base de datos (SQLite)
├── templates/            # Páginas web
│   ├── base.html         # Plantilla maestra (menús, diseño general)
│   └── index.html        # Pantalla principal
└── static/               # Archivos estáticos
    └── style.css         # Diseño y colores
```

## Base de datos
Vamos a crear la base de datos, como primer paso tenemos que diseñar las columnas que tendra nuestra tabla: 

- **ID:** Identificador unico del item.
- **Date:** Cuando se hizo el gasto.
- **Amount:** la cantidad que se gastó.
- **Badge:** La moneda con la que se pagó.
- **Category:** La categoria del gasto (comida, salud, recurrente, etc.).
- **P_method:** El metodo de pago (efectivo, debito, credito).
- **Description:** Una breve descripcion del gasto.
- **Type:** Si es un gasto o un ingreso.
- **Adress:** A quien o que se le hizo el pago.

Creamos el directorio del proyecto:
``` Bash
mkdir ~/RGOSS_app
cd ~/RGOSS_app
```

Preparamos la base de datos:
```Bash
nano init_db.py
```

Usamos la librería nativa `sqlite3` de Python para crear el archivo `expss.db`:

```Python
import sqlite3

def inicializar_bd():
    # Se conecta al archivo (si no existe, lo crea)
    conexion = sqlite3.connect('expss.db')
    cursor = conexion.cursor()
    
    # Borra la tabla anterior si existía
    cursor.execute('DROP TABLE IF EXISTS spendings')

    # Creación de la tabla
    cursor.execute('''
        CREATE TABLE spendings (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            amount REAL NOT NULL,
            badge TEXT NOT NULL CHECK(badge IN ('MXN', 'JPY', 'USD')),
            category TEXT NOT NULL CHECK(category IN ('Recurrente', 'Gusto', 'Imprevisto', 'Comida', 'Salida', 'Educación', 'Transporte', 'Salud')),
            p_method TEXT NOT NULL CHECK(p_method IN ('Efectivo', 'Credito', 'Debito')),
            description TEXT,
            type TEXT NOT NULL CHECK(type IN ('Pay', 'Profit')),
            adress TEXT
        )
    ''')

    # Guardar los cambios y cerrar
    conexion.commit()
    conexion.close()
    print("Base de datos creada con éxito.")

if __name__ == '__main__':
    inicializar_bd()
```

Ejecutamos el script:

```Bash
python3 init_db.py
```

Verás el mensaje de confirmación y, si usas `ls`, notarás que ya existe el archivo `expss.db`.

## Web App
Para mantener todo ordenado, vamos a usar un enotrno virtual en python. Dentro del directorio ejecutamos lo siguiente:

```Bash
# Instala el paquete para crear entornos virtuales
sudo apt install python3-venv

# Crea el entorno virtual llamado 'venv'
python3 -m venv venv

# Activa el entorno virtual
source venv/bin/activate
# Ahora veras (venv) al principio de la linea de comando

# Instala Flask
pip install Flask
```

>[!note]- ¿Por que un entorno virtual?
>Los sistemas operativos basados en Linux utilizan **Python** internamente para ejecutar procesos críticos, gestores de paquetes y configuraciones de red. Estas herramientas del sistema dependen de versiones muy específicas de ciertas librerías.
>Si instalas Flask de forma global usando `pip install`, corres el riesgo de actualizar o sobrescribir una librería que el sistema operativo estaba usando para funcionar. Esto puede romper partes de tu sistema y obligárte a reinstalar el sistema operativo completo. 
>==Al ejecutar el comando para crear el entorno, literalmente estás creando un directorio que actúa como una "burbuja" o un contenedor aislado.==

>[!tip] La carpeta `venv` solo debe contener los archivos internos de Python y las librerías que instales con `pip`

Crea el script principal de R.G.O.S.S que funcionará como el cerebro:

``` Bash
nano rgoss.py
```

Que debe contener el siguiente codigo:

```Python
from flask import Flask, jsonify, request
import sqlite3

app = Flask(__name__)

# Función para conectar a la base de datos
def get_db_connection():
    conn = sqlite3.connect('expss.db')
    # Esto permite acceder a las columnas por su nombre, como un diccionario
    conn.row_factory = sqlite3.Row 
    return conn

# Ruta principal de estado
@app.route('/')
def home():
    return jsonify({
        "system": "R.G.O.S.S.",
        "status": "Online",
        "active_modules": ["Expenses_API", "Wake_On_LAN"]
    })

# Ruta para ver todos los gastos 
@app.route('/api/spendings', methods=['GET'])
def get_spendings():
    conn = get_db_connection()
    spendings = conn.execute('SELECT * FROM spendings').fetchall()
    conn.close()
    
    # Convierte los resultados de la base de datos a formato JSON
    return jsonify([dict(row) for row in spendings])

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

## Hola mundo!
Finalmente, con el entorno virtual activado ejecuta el servidor:

```Bash
python rgoss.py
```

La terminal se quedará bloqueada mostrando mensajes de que el servidor está corriendo.

Para probar que esta funcionando, dentro de la red de Tailscale, abre el navegador y escribe la IP de R.G.O.S.S seguida del puerto 5000.

>[!example] http://100.888.88.888:5000

Debes ver una pantalla con un mensaje en forma de JSON, confirmando que estamos en linea.

>[!warning]- HTTP vs HTTPS
>**HTTP (Hypertext Transfer Protocol):** Es el protocolo base con el que funciona la web. Cuando envías o recibes datos por HTTP, la información viaja en **texto plano**.
>
>**HTTPS (Hypertext Transfer Protocol Secure):** Es la versión segura. Utiliza certificados digitales (conocidos como SSL o TLS) para encriptar los datos entre tu navegador y el servidor.
>
>El servidor de desarrollo que incluye Flask es muy básico y no tiene certificados de seguridad instalados; **solo entiende HTTP**. Flask estaba esperando un saludo en texto plano.
