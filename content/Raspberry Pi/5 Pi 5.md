La Raspberry Pi 5 es una **SBC (Single Board Computer)**. A diferencia de la [[3 Pi Pico]] (que es un microcontrolador), la Pi 5 es una computadora completa del tamaño de una tarjeta de crédito.

Posee procesador, memoria RAM, GPU y puertos USB; está diseñada para ejecutar un sistema operativo completo, típicamente usa Linux (Raspberry Pi OS). Es ideal para proyectos pesados: servidores locales, Edge AI, bases de datos, centros multimedia o automatización del hogar.

Incorpora, por primera vez, el **RP1**, un chip "Southbridge" diseñado internamente por Raspberry Pi que se encarga de gestionar casi todas las entradas/salidas, liberando al procesador principal y aumentando drásticamente la velocidad periférica.
# Especificaciones Técnicas
---

| Componente           | Especificación                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------- |
| **Procesador (SoC)** | Broadcom BCM2712, ARM Cortex-A76 Quad-core a 2.4 GHz                                     |
| **GPU**              | VideoCore VII (Soporta dos monitores 4K a 60Hz simultáneos)                              |
| **Memoria RAM**      | LPDDR4X (Opciones de 1GB, 2GB, 4GB, 8GB y hasta 16GB)                                    |
| **Almacenamiento**   | Ranura MicroSD (SDR104) o SSD NVMe (vía adaptador PCIe)                                  |
| **Red**              | Wi-Fi 5 (802.11ac) doble banda, Bluetooth 5.0 / BLE, Ethernet Gigabit                    |
| **Pines GPIO**       | 40 pines estándar (controlados a través del chip RP1)                                    |
| **Energía**          | USB-C PD (Power Delivery). Requiere fuente de **5V / 5A** (27W) para máximo rendimiento. |


# Pi 5 vs Pi 4
---

| Característica   | Raspberry Pi 4     | Raspberry Pi 5                     |
| :--------------- | :----------------- | :--------------------------------- |
| **CPU**          | Broadcom BCM2711   | Broadcom BCM2712 (2-3x más rápido) |
| **RAM**          | 1GB, 2GB, 4GB, 8GB | 4GB, 8GB                           |
| **PCIe**         | No expuesto        | **Sí** (permite SSDs NVMe rápidos) |
| **Botón Power**  | No                 | Sí                                 |
| **Salida Video** | 2x Micro HDMI (4K) | 2x Micro HDMI (4K @ 60Hz)          |
Si vienes de versiones anteriores, estas son las novedades clave de hardware que cambian el flujo de trabajo:
1. **Interfaz PCIe 2.0:** Por primera vez, tiene un conector FPC que, usando un adaptador (HAT), te permite conectarle un **disco de estado sólido (SSD NVMe M.2)**. Esto multiplica hasta por 10 la velocidad del sistema frente a las tarjetas MicroSD.
    
2. **Botón de encendido:** Históricamente, las Raspberry Pi se encendían al conectarlas y se apagaban "tirando del cable". La Pi 5 trae un botón de encendido/apagado por hardware nativo.
    
3. **Reloj en Tiempo Real (RTC):** Tiene un conector para una pequeña batería de reloj. Ahora la Pi puede mantener la hora exacta incluso si se queda sin internet o sin energía principal.
    
4. **Calor:** Al ser entre 2 y 3 veces más rápida que la Pi 4, genera más calor. Se considera casi obligatorio usar un disipador con ventilador para proyectos que exijan rendimiento constante.    

# Pi 5 vs Pico
---

- **Usa la Pi 5 si:** Tu proyecto necesita internet complejo (bases de datos, APIs web), procesamiento de video/cámara, correr contenedores de Docker, o requiere una interfaz gráfica (conectarle un monitor y un ratón).
    
- **Usa la Pico si:** Necesitas leer un sensor con precisión de milisegundos, controlar motores paso a paso en tiempo real, o hacer un proyecto que debe funcionar durante meses alimentado por una pequeña batería (la Pi 5 consume demasiada energía para eso).
